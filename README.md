# Zac’s Fitness — iPhone Home Screen App

This is a small installable Progressive Web App (PWA). Your entries are stored locally in the browser on the device. No account or server database is used.

## Publish it so your iPhone can install it
1. Create a free GitHub account if you do not already have one.
2. Create a new public repository named `zacs-fitness`.
3. Upload all four files in this folder (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Open the published HTTPS address in Safari on your iPhone.
7. Tap **Share → Add to Home Screen → Add**.

## Included
- Daily food and drink diary with calories, protein, carbs and fat
- Starting daily targets: 3,000 kcal, 180g protein, 380g carbs, 90g fat
- Weekly weigh-ins, waist measurement, notes and weight trend chart
- Workout log and the current Monday/Tuesday/Thursday/Friday/Saturday programme
- Dark black-and-gold design

## Important
- Data stays in that browser's local storage. Clearing Safari website data or changing devices can erase/leave behind entries.
- Use the Export/backup feature in a future version before relying on this as your only record. For now, keep your device/browser data intact.
- Nutrition targets are estimates, not medical advice.
